# CV Builder

A simple and responsive CV Builder built with React.

The application allows users to enter their personal information, education, work experience, and skills. The CV preview updates automatically as the user enters information.

## Features

- Add personal information
- Add multiple education entries
- Remove education entries
- Add multiple work experience entries
- Remove work experience entries
- Add and remove skills
- Live CV preview
- Edit / Preview mode
- Clear All button
- Load Example button
- Download CV as PDF
- Responsive design for desktop and mobile
- No page refresh is required while editing

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- html2pdf.js
